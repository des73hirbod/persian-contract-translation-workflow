# گزارش ساخت باندل — نسخهٔ 0.1.0-alpha

## دامنهٔ کار انجام‌شده

بر اساس سه پرامپت ارائه‌شده و پلان توافق‌شده، یک باندل سبک با دو نقش اجرایی ساخته شده است. این تحویل شامل **بازطراحی و آماده‌سازی بسته** است، نه اجرای آن روی قرارداد، آزمون عملکرد، سنجش دقت یا انتشار در GitHub.

## چه چیزی از فایل‌های اصلی حفظ شده است؟

| فایل مبنا | قواعد منتقل‌شده به باندل |
|---|---|
| استخراج و راستی‌آزمایی دقیق متن | PDF تصویری به‌عنوان مرجع حقیقت؛ پوشش صفحات؛ ارقام/نام‌ها/شروط حساس؛ نوشتار و حاشیه و جدول؛ ابهامات و اصلاحات منبع؛ ممنوعیت حدس و تحلیل حقوقی |
| ممیزی مستقل PDF ↔ Transcript | ممیزی جداگانه؛ عدم اصلاح پنهانی؛ طبقه‌بندی خطا و شواهد؛ بررسی حذف/اضافه/عدد/نفی/شرط؛ بازبینی موضعی موارد پرریسک؛ تفکیک خطا از عدم‌قطعیت منبع |
| پرامپت ترجمهٔ بیمه‌نامهٔ دریایی v2.0 | ترجمهٔ وفادار و قابل ردگیری؛ کنترل اصطلاحات/اسامی؛ حفظ افعال الزام‌آور، شرایط و نتایج؛ حفظ اعداد/تاریخ‌ها؛ ممیزی مستقل انگلیسی؛ اصلاحات موضعی؛ تفکیک مسئلهٔ منبع از خطای ترجمه |

## چه چیزی تغییر کرده است؟

- ده وظیفهٔ P00–P09 به سه حالت Worker و دو حالت Auditor تبدیل شدند؛ **وظایف حساس حفظ شده‌اند** اما اجراهای مستقل زائد و گزارش‌های هم‌پوشان اجباری نیستند.
- مرحلهٔ مفقودهٔ **Transcript Reconciliation** صریحاً بین Source Audit و ترجمه اضافه شد.
- قاعدهٔ مشخص برای استفاده از فایل‌های بین‌مرحله‌ای تعریف شد؛ `SOURCE_MASTER.md` مرجع عملیاتی ترجمه است و PDF همچنان مرجع نهایی خوانش تصویری باقی می‌ماند.
- نام ثابت بیمه‌نامه، چهار مورد HR نمونه، تعداد صفحات ثابت و نام‌های خاص نمونه از هسته حذف شدند؛ واژگان دریایی به پروفایل اختیاری منتقل شدند.
- نشانگرهای مختلف ابهام و عناصر دست‌نویس/مهر/امضا در ترجمه پوشش داده شدند.
- خروجی‌های کم‌تعداد Markdown جایگزین انبوهی از فایل‌های اجباری/JSON شدند؛ متادیتای ساختگی و Hashهای چندباره درخواست نمی‌شود.
- قاعدهٔ بی‌اعتمادی به دستورهای داخل PDF، چگونگی ادامهٔ اسناد بلند، و بیان محدودیت مشاهدهٔ واقعی تصاویر اضافه شد.
- وضعیت‌های `DONE`، `REVIEW_REQUIRED`، `PARTIAL`، `STOPPED` جدا شدند. **وجود DONE هیچ تضمین حقوقی یا آماری نمی‌دهد.**

## عمداً ساخته یا انجام نشده است

- هیچ PDF نمونه یا واقعی برای تست تهیه یا اجرا نشده است.
- هیچ نتیجهٔ Accuracy، Cost، Latency یا Benchmark تولید نشده است.
- هیچ `tests/`, gold reference, synthetic fixture, CI, خودکارسازی API یا پایگاه داده‌ای ساخته نشده است.
- هیچ گواهی موفقیت، PASS آزمایشی یا ادعای اعتبار قانونی صادر نشده است.
- هیچ Repository از طریق این بسته ایجاد یا در GitHub منتشر نشده است.
- برای آماده‌سازی انتشار عمومی، نسخهٔ پیشنهادی `LICENSE` با مجوز MIT افزوده شد. منتشرکننده باید حق انتشار محتوا و قصد اعطای این مجوز را تأیید کند؛ بدون تأیید او نباید تصور کرد این انتخاب نهایی و غیرقابل تغییر است.

## برای استفادهٔ آینده

از `START_HERE_FA.md` شروع کنید. برای انتشار از `docs/GITHUB_SETUP_FA.md` استفاده کنید؛ پیش از انتشار با مجوز MIT موافقت کنید یا آن را تغییر دهید و مطمئن شوید هیچ سند یا اطلاعات مشتری در فایل‌ها و تاریخچهٔ Git وجود ندارد. توسعهٔ تست‌ها و خودکارسازی می‌تواند در نسخه‌های بعدی انجام شود، اما بخشی از این تحویل نیست.
